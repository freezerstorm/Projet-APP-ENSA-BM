# Projet-APP-ENSA-BM
Projet de chargement sans fil entre deux voitures
Ici vous verrez tous les codes utilisés dans ce programme.
On a au moins trois codes:
1 code du robot suiveur de ligne qui fait office de voiture
2 code qui sert de firmware pour les décisions et la communication via Bluetooth pour la première voiture
3 code firmware qui prend les décisions pour la deuxième voiture (statique dans notre projet car fait office de voiture en panne de charge)
